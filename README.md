Ecommerce Data Analysis

E-commerce sales data analysis project using Excel and SQL.

Project Overview

This project analyzes e-commerce sales data to understand sales performance across different categories, cities, and payment methods.

Tools Used

- Microsoft Excel
- SQL

Key Metrics

- Total Sales: ₹273,100
- Average Order Value: ₹54,620

Analysis Performed

1. Sales by Category

Analyzed total sales for:

- Electronics
- Fashion

2. Sales by City

Analyzed total sales across:

- Bangalore
- Hyderabad
- Chennai

3. Sales by Payment Method

Analyzed sales using:

- UPI
- Card
- Cash

Excel Analysis

Created PivotTables and PivotCharts to visualize:

- Total sales by category
- Total sales by city
- Total sales by payment method

SQL Analysis

Used SQL queries to calculate:

- Total sales
- Sales by category
- Sales by city
- Average order value

Conclusion

The analysis provides a simple overview of e-commerce sales performance and demonstrates practical use of Excel and SQL for data analysis.
